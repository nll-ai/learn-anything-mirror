# learn-anything-mirror

Static mirror of <https://learn-anything.nonlinearlabs.ai> served by GitHub
Pages at <https://nll-ai.github.io/learn-anything-mirror/>.

- **Artifact-only repo**: every file on `main` is generated by the
  `Deploy mirror` workflow in the private [`nll-ai/learn-anything`](https://github.com/nll-ai/learn-anything)
  repo — do not edit by hand; the next deploy force-overwrites the branch.
- Purpose: a fallback URL on GitHub/Fastly infrastructure for visitors on
  corporate intranets that cannot reach Vercel (issue
  [nll-ai/learn-anything#196](https://github.com/nll-ai/learn-anything/issues/196)).
- Signups posted here go to the same production waitlist backend; account
  sign-in may be unavailable from this origin.
